### Kokoro Project

#### Overview
Kokoro Project is a lightweight, extensible neural network framework written in C++17, designed for flexibility and efficiency in building and training machine learning models. It supports a variety of layers, optimizers, and utilities for data preprocessing and model management.

#### Features
- **Layers**: Dense, GRU, LSTM, Conv1D/2D/3D, Dropout, Embedding, and more.
- **Optimizers**: SGD, Adam, Adamax, AdamW, Nadam.
- **Preprocessing**: Numerical standardization/normalization, text tokenization, image processing.
- **Callbacks**: Model checkpointing, early stopping, learning rate scheduling, history logging.
- **Quantization**: Support for reducing model precision (e.g., int8).
- **Serialization**: Save and load models efficiently.

#### Requirements
- C++17 compiler (e.g., g++ 7.0+)
- Standard libraries only
